# Code provenance and reproduction

This directory contains the Python source files used to generate the numerical
results and supporting figures in the Supplemental Material. It includes the
top-level experiment drivers together with the `experiments/` and `src/` support
modules. Virtual environments, caches, IDE settings, prior convergence backups,
and generated working outputs are intentionally excluded.

Install the dependencies listed in `requirements.txt` and run individual
experiments from this directory:

```bash
python run_benchmarks.py
python run_certificate_search.py
python run_exact_sdp_m8_probe.py
python run_favorable_regime_sweep.py
python run_resource_sensitivity.py
python run_qec_hierarchy.py
```

The main plotting entry points are `make_figures.py` and
`plot_favorable_regime_sweep.py`. They write working CSV outputs to `results/`
and PDF/PNG figures to `figures/` under this directory.

The CSV files in `../data/` are the canonical snapshot used by the Supplemental
Material. To regenerate the packaged supporting figures from that snapshot,
copy the required CSV files to `results/`, then run:

```bash
python make_figures.py
python plot_favorable_regime_sweep.py
```

The PDF files in `../figures/` were generated by these plotting scripts from
the recorded numerical inputs.

Compile the Supplemental Material from the `SM/` directory:

```bash
latexmk -pdf supplemental.tex
```
