# Held-out independence audit

Status: **DRAFT_ONLY**,48 distinct candidates,0 duplicate candidate vectors,0 Phase1D duplicate priors,0 archival-vector collisions,0 observed seed collisions. No new payloads, overlaps, E2 diagnostics or SDP outcomes were generated.

CONFIRMATORY_PRIORS_DRAFT.csv records each full vector and SHA256 of its little-endian float64 bytes. Vectors are generated in the pinned original NumPy2.4.4 environment using the existing source generator. Both byte hashes and within-draft numerical vector equality at absolute1e-14 are checked. The script compares all40 Phase1D entries (24 distinct across M), including the two primary positives, Phase1C stored vectors, and accessible CSV prior fields from root data, the original SM and authoritative paper_data/results. Archival comparisons use absolute5e-8 to conservatively catch collisions with rounded legacy vectors. The new random seeds do not occur in scanned development/legacy seed fields. Exact scanned-file/vector counts are in audit_phase2_5/heldout_check.json.

Families:10 deterministic Zipf exponents,20 new Dirichlet draws (10 each alpha1/2),10 new near-uniform draws using the original0.04/M Gaussian rule,8 controlled-skew grid vectors. Zipf/skew seeds are null because their vector does not depend on a seed; the generator receives a constant placeholder0 internally with no random draw used. These are distinct deterministic prior cases, not independent stochastic replicates. Random-seed disjointness is a reproducibility/leakage check, not a proof of statistical independence.

The grids avoid the old Zipf0.8 and strong-skew0.75 exact priors. They were declared before generating any payload/certificate, not selected using length saving, overlap, E2 or preview success. Extending the scan from packaged SM to authoritative paper_data identified TWO initial collisions: controlled-skew0.82 and0.92 were already used in the old favorable sweep. They were replaced by0.83 and0.93 solely to remove input duplication, with no geometry/endpoint generated. The final draft has0 duplicates. The superseded draft is preserved in audit_phase2_5/superseded_draft_01/ and the collision/replacement ledger is machine recorded. If a future independent check finds another collision before freeze, revise visibly and obtain new human approval. After freeze there is no prior replacement based on outcomes.

Important limit: prior novelty is verified against accessible stored vectors, not every conceivable prior ever viewed by an author. Rounded legacy vectors cannot prove full-precision nonexposure, and no external record guarantees authors never studied the chosen parameters. An author attestation of no prior endpoint evaluation, an immutable approved manifest and outcome-blind execution are required before calling the batch held-out. Source families and the G2 architecture were learned/chosen during development; this is **in-family held-out prior validation**, not an independent test of an unselected model family.

The fixed mixture of deterministic grids and pseudorandom draws is not iid from a natural source population. Primary counts support held-out existence/replication, not a prevalence estimate or confidence interval for a universal advantage rate.
