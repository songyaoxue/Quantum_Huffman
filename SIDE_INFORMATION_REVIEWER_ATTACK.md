# Side-information reviewer attack

C1: Orthogonal labels reveal the deterministic classical function g(s), so they are source-correlated classical information, despite their quantum-register representation.

C2--C3: The comparison matches the complete partition, label alphabet and conditional measurement model, not merely the number of labels. Frozen code applies one common partition to both arms. F uses its own conditional priors p_i/p_g and its own payloads in a grouped dual. This removes a one-arm-only information advantage. Measurement success comparison is fair for the specified ideal task.

C4--C5: C_A is ideal label width. It is neither Shannon information H(g), average compressed bits nor a transport cost. Main lines 125--129 correctly exclude architecture-specific costs, but "charged" should become "recorded identically". Main lines 260--264 should use comparison-coordinate terminology. No main-text equation establishes real communication overhead.

C6: G2 uses sorted (-p_i,i), greedy least accumulated mass and group-index tie breaking. This was independently reconstructed from stored priors and agrees with every registered G2 partition. No overlap, phase, SDP or certificate sign is used. The rule was selected as one of four prospective local regimes after earlier model development; it is not a wholly development-independent discovery.

C7: A reviewer can reasonably call G2 engineered side information. The answer is task definition, not a claim that G2 is quantum decoding: both receivers learn the same group, then distinguish different length-induced payload ensembles. Positive bounds isolate differences of those specified ensembles, not the benefit of labels themselves. No classical-versus-quantum advantage has been demonstrated.

SIDE_INFORMATION_FAIRNESS: PASS for ideal matched conditional tasks. It does not imply operational transport-resource fairness outside that model. Proposed explanation: "The classical partition defines the side information supplied to both receivers; the subsequent conditional quantum discrimination tasks differ only through their specified payload states."
